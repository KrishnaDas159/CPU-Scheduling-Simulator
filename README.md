# 🖥️ CPU Scheduling Simulator (MERN Stack)

🎉 A fully functional and interactive **CPU Scheduling Simulator** built using the **MERN stack**, designed to help students and developers understand and visualize different CPU scheduling algorithms.

The application is providing real-time simulation, visual Gantt charts, and automatic performance analysis.

---

## ✨ Key Features

### 🔄 Scheduling Algorithms (6)
- First Come First Serve (**FCFS**)
- Shortest Job First (**SJF – Non-Preemptive**)
- Shortest Remaining Time First (**SRTF – Preemptive**)
- Priority Scheduling (**Non-Preemptive**)
- Priority Scheduling (**Preemptive**)
- Round Robin (**RR**)

### 🧩 Interactive Process Management
- Add, edit, and delete processes
- Input validation for arrival time, burst time, priority, and time quantum

### 📊 Visualization
- Dynamic **Gantt Chart** with color-coded processes
- Clear execution timeline for each algorithm

### 📈 Performance Metrics
- Turnaround Time
- Waiting Time
- Average Turnaround Time
- Average Waiting Time

### 📱 Responsive UI
- Fully responsive design
- Works seamlessly on desktop, tablet, and mobile devices

### ⚡ Real-Time Simulation
- Instant computation and visualization
- Detailed execution breakdown per process

## 🧪 How to Use

1. Open the live application
2. Add processes using the form:
   - Process ID
   - Arrival Time
   - Burst Time
   - Priority (if applicable)
3. Select a scheduling algorithm from the dropdown
4. (For Round Robin) Enter the time quantum
5. Click **Simulate**
6. View:
   - Gantt Chart
   - Execution timeline
   - Waiting & turnaround times
   - Average metrics
